# Bank Support Prompt Chain

A prompt chaining banking customer support system using Node.js and OpenRouter API.

## Installation

```bash
npm install
```

## Setup

Create a `.env` file:

```env
OPENROUTER_API_KEY=your_api_key
MODEL_NAME=openai/gpt-4o-mini
```

## Run

```bash
node main.js "My debit card was charged twice"
```
